# The Novelist — 인수인계

다른 AI나 개발자에게 이 프로젝트를 넘길 때 이 문서를 먼저 읽히면 됩니다.
작성일 2026-08-11.

---

## 1. 이 앱이 뭔가

**한국어 웹소설 집필 도우미.** 핵심은 이렇습니다.

> AI가 세계관·인물·회차별 줄거리와 집필 가이드를 짜준다. **본문은 작가가 앱 안에서 직접 쓴다.**

AI가 소설을 대신 써주는 앱이 **아닙니다.** 판매 빌드에서는 AI 본문 대필 기능이
꺼져 있습니다(AS 부담 때문에 의도적으로 뺐습니다). 다만 "본문 예시"(약 1,000자,
참고용 한 토막)는 라이트 요금제 이상에서 제공합니다.

## 6. 반드시 지켜야 할 것 (사고 이력)

### 6-1. 이용자 글은 무슨 일이 있어도 날아가면 안 된다

과거 `/rename`(이름 일괄 변경) 기능이 **이미 쓴 모든 회차 본문을 전역 문자열
치환**해서, 짧은 이름 하나 바꿨다가 본문 전체가 훼손된 사고가 있었습니다.
그 엔드포인트는 **삭제**했고 `server/writer.py`에 경고 주석이 남아 있습니다.

지켜야 할 규칙:

- 이미 쓴 본문을 프로그램이 통째로 바꾸는 기능을 **다시 만들지 말 것**
- 덮어쓰기 전에는 반드시 스냅샷을 남길 것 (`_stash(...)` → 되돌리기 가능)
- 표기를 바꾸려면 '기억하기'(canon) 사전에 등록 → **다음 회차부터** 반영

### 6-2. 설계 중이던 내용도 날아가면 안 된다

마법사(15단계)의 상태는 `localStorage`(`thelife_wizard`)에 자동 저장됩니다.
새로고침·앱 재시작에도 하던 단계로 복구됩니다. 이 장치를 건드릴 때 조심하세요.
본문 에디터도 타이핑 700ms 뒤 자동 임시저장합니다.

### 6-3. 정적 파일 캐시

배포해도 브라우저가 옛 JS/CSS를 물고 있어 "옛날 화면"이 보이던 문제가 있었습니다.
`main.py`의 `FreshStatic` 클래스가 `Cache-Control: no-cache`를 붙여 해결했습니다.
**이걸 제거하지 마세요.**

## 7. 요금제 구조

`server/writer.py`의 `TIERS`가 유일한 기준입니다. 화면은 이 값을 그대로 그립니다.

| | 무료 | 라이트 ₩4,900 | 프로 ₩9,900 |
|---|---|---|---|
| AI 회차 줄거리 | 3화 | 20화 | 70화 |
| 화당 줄거리 | 100자 | 250자 | 450자 |
| AI 인물 생성 | 3명 | 7명 | 10명 |
| 작품 수 | 1개 | 10개 | 무제한 |
| 직접 쓰기 | ✓ | ✓ | ✓ |
| 본문 예시(1,000자) | 안 됨 | 하루 3건 | 하루 10건 |
| 하루 AI 사용 | 40회 | 250회 | 800회 |
| 광고 | 있음 | 없음 | 없음 |

- 직접 쓰기는 **모든 등급 개방**입니다. 핵심 기능이라 잠그면 앱이 성립하지 않습니다.
- 판매 빌드(`LAUNCH_MODE=1`)에서는 문체 학습·AI 본문 대필·펜을 **끕니다.**
  `LAUNCH_TIER_COPY`에서 플랜 문구도 함께 바꿉니다.
  (없는 기능을 플랜에 적으면 스토어 심사에서 걸립니다)

## 9. 지금 알려진 문제 (미해결)

화면 계산으로 직접 잰 것들입니다. **AI 응답과 무관하므로 확실합니다.**

1. **긴 목록에서 상단바가 화면 밖으로 나감.** 25화 목록을 내리면 홈·메뉴 버튼이
   사라져 돌아갈 길이 없음 (측정값 `top: -570px`). → `.app-top`을 `position: sticky`로.
2. **줄거리/가이드 목록이 제목만 나열됨.** 어느 화가 무슨 내용인지, 어디까지 썼는지
   목록에서 안 보임. → 줄거리 한 줄 미리보기 + 집필 여부 표시 필요.
3. **무료인데 1단계에서 25화·70화를 고를 수 있음.** 한도(3화)는 한참 뒤 줄거리
   단계에서야 고지됨. → 고르는 자리에서 즉시 표시.
4. **진행 표시 점이 4개인데 실제는 15단계.** `writer.html`의 `.wz-dot` 4개 하드코딩.
5. **인물 상세의 항목 번호가 10~16번.** 내부 스펙 번호가 그대로 노출됨. 1~7이어야 함.
6. **인물 단계 안내문 불일치.** "이름과 나이만 적고"라고 하는데 목록에 입력칸이 없음
   (상세로 들어가야 있음). `wzspec.js`의 `sub` 문구 수정 필요.
7. **쓰기 화면 `줄거리/가이드 보기` 버튼 글자가 두 줄로 깨짐.** 칸이 좁음.

### 확인되지 않은 것 (조사 필요)

- `POST /works/build`가 마법사 마지막에 **AI를 세 번째로 호출**합니다
  (세계관 1회 + 회차 전개 1회 + 여기서 '설계도' 1회). 실패하면 작품이 만들어지지
  않습니다. 이미 인물·세계관·줄거리가 다 있는데 또 만드는 구조라 **비용과 실패
  지점이 늘어납니다.** 구조 개선 후보이지만, 실제 운영에서 얼마나 실패하는지는
  측정된 바 없습니다. (로컬 가짜 AI로 재현한 실패는 테스트 환경 탓이었습니다)
- 사용자가 보고한 "프로 25화인데 몇 화만 나온다"는 모델이 JSON을 중간에 끊는
  문제로 보고 보충 생성 로직을 넣었으나, 실제 환경에서 해결됐는지 미확인.

## 10. 작업 규칙 (프로젝트 주인의 요구)

- **코드를 고치기 전에 먼저 생각을 말하고 물어볼 것.**
- 반복 표현·반복 장면을 극도로 싫어함. `writer.py`에 3중 방지 장치가 있음
  (`_overused_expressions` / `_recurring_motifs` / `_overused_words`).
- 이모지를 UI에 쓰지 말 것. 기기에 따라 깨짐. `writer.js`의 `ICO` SVG 세트를 쓸 것.
- 버튼 디자인은 통일할 것. 저장 버튼은 전부 같은 모양.
- 화면 아래 고정 버튼이 내용을 가리는 사고가 반복됨. 마법사는 `wzPad()`로
  버튼 높이를 재서 여백을 잡음. 숫자를 박아두지 말 것.
- 주석과 문구는 한국어로.
