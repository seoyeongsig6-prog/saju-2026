# 더 노벨리스트 — 스토어 등록 문안

## 짧은 설명

아이디어 한 줄을 세계관·인물·회차별 줄거리로 설계하고, 내 손으로 완성하는 웹소설 작업실

## 상세 설명

더 노벨리스트는 AI가 소설 전체를 대신 쓰는 앱이 아닙니다. 작가의 아이디어를 작품의 세계관,
등장인물, 핵심 설정과 회차별 줄거리로 정리해 주고, 작가는 앱 안에서 직접 본문을 집필합니다.

작품 전체의 시놉시스를 기준으로 세계관과 인물이 서로 어긋나지 않게 설계하고, 필요한 회차에는
약 1,000자의 본문 예시를 참고할 수 있습니다. AI가 제안한 내용은 언제든 직접 고칠 수 있으며,
작품 설정을 수정하면 다음 집필에 반영됩니다.

주요 기능:

- 아이디어에서 세계관 자동 설계
- 작품에 맞는 주인공과 등장인물 구성
- 회차별 줄거리 생성·편집
- 설정과 인물 정보 기억하기
- 방해 없는 직접 집필 에디터
- MASTER/PRO 작품 파일 내보내기
- 기기 변경을 위한 복구 코드

FREE로 전 과정을 시작하고, 더 많은 작품과 AI 설계가 필요하면 MASTER 또는 PRO를 선택하세요.

## 심사 메모

앱은 로그인 없이 기기별 익명 식별자로 동작합니다. 설정에서 데이터 사본 받기와 모든 데이터 삭제가
가능하며, 기기 변경 시 복구 코드를 사용할 수 있습니다. 구독 화면의 “구매 복원”으로 기존 구독을
복원할 수 있습니다. AI는 세계관·인물·줄거리·1,000자 참고 예시만 생성하며 전체 본문 대필 기능은
제공하지 않습니다.
